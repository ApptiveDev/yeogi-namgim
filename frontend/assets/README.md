# 에셋 관리

- 여러 화면에서 쓰는 스티커는 `images/stickers/`의 원본 하나를 공유한다. 마이페이지·친구·쪽지 작성 화면이 같은 이미지를 다시 내보내 각 폴더에 복사하지 않는다.
- 스티커 표시 크기는 각 컴포넌트의 스타일로 지정한다. 공통 원본은 기존 파일 중 해상도가 높은 버전을 유지했다.
- 화면별 SVG는 색상·여백·표현이 다른 경우 별도로 유지한다. 모양이 비슷하다는 이유만으로 바꾸지 않는다.
- PNG의 `@2x`·`@3x`는 화면 밀도별 리소스다. 코드에서 기본 파일만 참조해도 함께 사용되므로 중복 파일로 삭제하지 않는다.
- `app.json`이 참조하는 앱 아이콘·스플래시와 `expo.icon/icon.json`의 내부 이미지도 확인한다.

이슈 #126에서 공통 스티커 7개를 이 폴더 구조로 모으고, 중복 이미지 7개와 사용처가 없는 이미지 20개를 제거했다. 작성 화면 뒤에 가려져 있던 이전 위치 미리보기와 관련 핀 PNG 3개도 제거했다. 지도 쪽지는 `NoteMapLayer`의 숫자 원으로 표시한다. 이미지 내용을 다시 인코딩하거나 SVG의 그림을 변경하지 않았다.
