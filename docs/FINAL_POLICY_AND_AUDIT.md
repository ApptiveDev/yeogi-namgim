# 최종 기획 기준과 기존 구현 점검

확인일: 2026-10-28 / 담당 범위 정정: 2026-10-29. 이 문서는 이번 대화에서 제공된 기획자 추가 답변과 파란색 최종 와이어프레임을 기존 계약·구현에 대조한 기록이다.

## 기준 우선순위

1. 기획자의 최신 확정 답변
2. [Figma 최종 와이어프레임](https://www.figma.com/board/na2BfVQ4q6GPZ99RZl43bt?node-id=98-133)의 지도·친구·보관함·마이 화면
3. 위 두 자료와 일치하는 기존 기획서
4. 이 저장소의 개발 계약·역할분담안

기획자는 노션 7번 미확정 항목 상당 부분이 잘못 들어갔다고 정정했다. 기존 7번에 남았다는 이유만으로 최신 확정 규칙을 다시 미정으로 취급하지 않는다. Figma 구조에서 `98:140`은 지도탭, `98:117`은 지도 흐름 이미지, `99:151`은 친구탭, `102:212`는 친구 흐름 이미지다.

## 확정된 동작

- 지도에는 공개 범위상 노출 가능한 쪽지 위치를 표시한다. 실제 열람할 수 없는 쪽지는 목록·미리보기에서 제외한다.
- 전체 지도 목록은 익명이다. 친구 지도 목록에는 작성자 이름을 표시한다.
- 친구 지도는 친구의 `FRIENDS` 쪽지만 포함한다. 친구의 `PUBLIC` 쪽지는 제외한다.
- 내 쪽지와 접근 권한이 있는 저장 쪽지는 거리·위치 권한 없이 열람한다.
- 다른 사람의 미저장 쪽지는 현재 위치에서 200m 이내일 때 열람한다. 읽었어도 저장하지 않았다면 이동 후 다시 거리 조건을 적용한다.
- 목록을 열고 이동한 뒤 상세로 들어갈 때 현재 좌표로 다시 검사한다. 목록에 표시됐다는 이유로 영구 열람 권한을 발급하지 않는다.
- 위치 권한 없이 지도 탐색은 허용한다. 현재 위치가 필요한 새 쪽지 작성과 타인 미저장 쪽지 열람은 제한한다.
- 열람 가능한 쪽지가 한 개면 목록 없이 상세, 여러 개면 목록으로 이동한다.
- `가까이 가야 볼 수 있어요` 잠금 팝업은 제거한다. 원 밖 쪽지는 열람 목록에 넣지 않는다. 서버의 `NOTE_LOCKED` 오류는 이동 후 상세 요청 등 우회 요청을 거절하기 위해 유지한다.

지도 시안 하단의 탭 규칙은 **화면에 그린 200m 원의 너비 / 화면 너비**로 전환한다. 1/3 미만이면 탐색 모드에서 물방울 탭 시 확대만 하고, 1/3 이상이면 열람 모드다. 이 화면 비율은 프론트가 지도 투영·화면 너비로 판정하며, 백엔드는 임의의 고정 줌 레벨이나 픽셀 값을 만들지 않는다.

Figma 이미지에는 원 밖 잠금 팝업과 친구의 전체 공개 포함 설명이 남아 있다. 이 두 설명은 최신 기획자 답변에 의해 대체된다. 상세 화면의 익명 작성자 이름 등도 최신 답변의 전체 지도 익명 규칙을 따른다.

## 기존 구현과의 대조

| 대상 | 확인 결과와 처리 |
| --- | --- |
| 이메일 가입·로그인·재발급·로그아웃 | 기존 인증 계약을 유지할 수 있다. 이번 지도 정책 변경으로 인증 데이터 모델을 바꿀 필요는 없다. 실제 SMTP 수신·카카오 로그인·회원 화면 연동은 별도 작업이다. |
| 회원 쪽지 작성·내 쪽지 조회 | 회원 작성자, 좌표·서버 시각, 공개 범위·색상·장소 구조와 본인 거리 예외는 유지한다. 색상 팔레트의 프론트 선택값·주소 필드 전달은 아직 연동해야 한다. |
| 친구 초대·관계·목록 | 최종 친구 시안의 일회용 코드/링크, 별도 승인 없이 친구 되기, 양쪽 목록 반영과 일치한다. 실제 카카오톡 공유·앱 링크 진입은 미연동이다. |
| 기존 비회원 작성 화면 | 친구·개인을 골라도 선택값이 빠진 비회원 공개 요청을 보내는 불일치가 있다. 프론트 담당에게 회원 API 연결 또는 공개 이외의 비회원 작성 차단을 인계한다. 이번 백엔드 PR에는 프론트 수정을 포함하지 않는다. |
| 기존 회원 타인 열람 | 이전 단계에서는 권한 구현 전이라 전부 404였다. 이번 지도 작업에서 공통 공개 범위·친구·거리 판정을 연결한다. 열람·저장 담당은 이 공통 판정과 읽음 기록을 이어서 확장한다. |
| 기존 문서 | 친구 PUBLIC 포함, 한 개 상세 이동, 상세 거리 재검사와 확대 기준을 미정으로 남긴 항목을 정정한다. |

화면 전체가 완성됐다는 의미는 아니다. 기존 프론트는 비회원 흐름이며 최종 회원 지도·필터·숫자 물방울·목록·1/3 모드 전환이 아직 연결되지 않았다. 이번 변경은 백엔드 지도 API와 관련 계약·점검 문서에 한정한다. 프론트의 화면 배치·에셋을 최종 시안과 일치시키는 작업은 후속이다.

## 유지해야 할 담당 경계

- 지도 담당: 화면 범위·필터·정렬·페이지 조회, 표시용 응답 조립과 공통 조회 계약.
- 열람·저장 담당: 저장·취소·읽음 기록 쓰기, 실제 저장/읽음 조회 구현, 보관함과 접근 판정의 연결.
- 프론트: 비회원 화면에서 친구·개인 선택이 공개 저장으로 바뀌는 문제 수정, 회원 토큰 연결, 지도 변경에 따른 페이지 갱신, 물방울 묶음·숫자 표시, 1/3 기준, 목록/상세 이동·뒤로 가기, 주소·색상 전달.

저장 소스가 없으면 저장 필터는 `503 MAP_DATA_UNAVAILABLE`다. 저장·읽음 소스가 없는 일반 지도 응답의 `isSaved/isRead`는 null이며 ‘저장 안 함/안 읽음’으로 확정해서는 안 된다. 운영용 빈 저장 서비스나 무조건 허용하는 임시 권한 서비스를 넣지 않는다. 연결 방법은 [회원 지도 API](MEMBER_MAP_API.md)를 따른다.

아직 답변이 보류된 내 쪽지 저장 취소·수정·삭제·공개 범위 변경과 저장 후 관계 변경 정책은 임의로 추가하지 않는다.
